# cPanel Deployer ⚡
### سیستم سبک، مستقل و بدون دیتابیس برای مدیریت و دیپلوی سایت‌ها روی cPanel

سیستم مستقل پیاده‌سازی‌شده با **PHP 8.1+ خالص** جهت استقرار و مدیریت سریع وب‌سایت‌های استاتیک و اسکریپت‌های مستقل PHP روی هاست‌های اشتراکی cPanel بدون نیاز به داکر، دیتابیس، دسترسی SSH یا وابستگی‌های سنگین.

---

## ۱. ویژگی‌های کلیدی و معماری

- **مبتنی بر PHP خالص:** بدون نیاز به فریم‌ورک‌های سنگین (مانند Laravel)، کامپوزر در محیط پروداکشن، یا ابزارهای Node.js/Docker.
- **بدون دیتابیس:** ذخیره اطلاعات سایت‌ها، لاگ‌ها و وضعیت در فایل‌های محافظت‌شده JSON با قفل‌گذاری هم‌زمانی (`flock`).
- **نصب آسان در cPanel File Manager:** استقرار فقط با آپلود و Extract یک فایل ZIP.
- **مسیر اختصاصی و تصادفی مدیریت:** ایجاد پوشه تصادفی مانند `https://example.com/panel-a7b8c9d0e1f2/` جهت جلوگیری از اسکن مسیرهای عمومی مثل `/admin`.
- **نگاشت مستقیم فایل‌ها (Native cPanel Mapping):** هر سایت در پوشه مستقل خود در `public_html/{slug}/` مستقر شده و آپاچی/لایواسپید مستقیماً فایل‌های استاتیک و اسکریپت‌های PHP آن را اجرا می‌کند (بدون لایه کند پروکسی).
- **حذف هوشمند پوشه ریشه اضافی در ZIP:** در صورتی که فایل‌های سایت داخل یک پوشه درون ZIP فشرده شده باشند، سیستم به‌صورت خودکار محتوا را در ریشه پوشه مقصد استخراج می‌کند.
- **به‌روزرسانی اتمیک با امکان Rollback:** فایل‌های جدید ابتدا در پوشه موقت بررسی شده و پس از تأیید سلامت، جایگزین نسخه قبلی می‌شوند. در صورت بروز خطا، نسخه قبلی بازیابی خواهد شد.
- **امنیت سخت‌گیرانه آپلود:** محافظت در برابر حملات Zip Slip (مسیرهای `../` یا symlinkها) و حملات فشرده‌سازی Decompression Bomb.
- **ضد نفوذ Brute-Force:** محدودیت تعداد تلاش‌های ورود (حداکثر ۵ تلاش ناموفق در ۱۵ دقیقه) و قفل موقت بر اساس IP.
- **محافظت CSRF و سشن‌های امن:** توکن ضد جعل یکتا برای تمام فرم‌ها و تنظیمات امن کوکی (`HttpOnly` و `SameSite=Lax`).
- **رابط کاربری مدرن، مینیمال و راست‌چین (RTL):** طراحی تمیز، واکنش‌گرا و سبک بدون هیچ فریم‌ورک سنگین خارجی.

---

## ۲. پیش‌نیازهای سرور

- **PHP 8.1** یا بالاتر
- اکستنشن‌های استاندارد فعال در PHP (پیش‌فرض تمام هاست‌های cPanel):
  - `ext-zip` (برای باز کردن و استخراج آرشیوهای ZIP)
  - `ext-json` (برای خواندن و ذخیره تنظیمات)
  - `ext-fileinfo` (برای بررسی هدر و نوع فایل‌ها)
  - `ext-session` (برای مدیریت نشست‌های احراز هویت)
- دسترسی نوشتن برای کاربر وب روی پوشه `public_html`

## ۳. مراحل نصب گام‌به‌گام روی cPanel

### گام اول: آپلود پکیج به هاست
1. وارد کنترل‌پنل **cPanel** شوید.
2. به بخش **File Manager** بروید و وارد پوشه `public_html` شوید.
3. فایل `cpanel-deployer.zip` را در `public_html` آپلود کنید.
4. روی فایل کلیک‌راست کرده و گزینه **Extract** را بزنید تا فایل‌ها مستقیماً در `public_html` استخراج شوند:
   ```text
   public_html/
   ├── install.php
   ├── index.php
   ├── .htaccess
   ├── panel_core/
   ├── panel_data/
   └── samples/
   ```

### گام دوم: اجرای نصب‌کننده در مرورگر
1. آدرس دامنه خود را به‌همراه `install.php` در مرورگر باز کنید:
   ```text
   https://your-domain.com/install.php
   ```
2. صفحه نصب پیش‌نیازهای سرور را بررسی می‌کند.
3. **رمز عبور مدیریت** (حداقل ۸ کاراکتر) را تعیین کنید.
4. سیستم یک شناسه تصادفی برای پنل پیشنهاد می‌دهد (مثلاً `panel-e4b2d18a59c3`)؛ در صورت تمایل می‌توانید آن را تغییر دهید.
5. روی دکمه **«تکمیل نصب و راه‌اندازی پنل»** کلیک کنید.

### گام سوم: ذخیره آدرس پنل
- پس از نصب موفق، آدرس اختصاصی پنل به شما نمایش داده می‌شود (مثال: `https://your-domain.com/panel-e4b2d18a59c3/`).
- **نکته امنیتی:** حتماً این آدرس را بوک‌مارک یا ذخیره کنید؛ هیچ مسیر عمومی مثل `/admin` وجود ندارد.
- فایل `install.php` بلافاصله به‌صورت خودکار **قفل** شده و اجرای مجدد آن غیرممکن خواهد بود.

## ۴. راهنمای دیپلوی و مدیریت سایت‌ها

### دیپلوی سایت جدید:
1. با رمز عبور تعیین‌شده وارد پنل شوید.
2. روی دکمه **«دیپلوی سایت جدید»** کلیک کنید.
3. **نام سایت** و **شناسه مسیر (Slug)** را وارد کنید (مثلاً `shop`).
   - آدرس نهایی سایت شما خواهد بود: `https://your-domain.com/shop/`
4. فایل ZIP محتویات سایت را انتخاب کرده یا داخل کادر بکشید و رها کنید.
5. روی **«شروع دیپلوی»** کلیک کنید تا نوار پیشرفت تکمیل و سایت فعال شود.

### انواع سایت‌های پشتیبانی‌شده:
- **سایت‌های استاتیک:** شامل `index.html`، فایل‌های CSS، JavaScript، تصاویر، فونت‌ها و صفحات داخلی HTML.
- **اسکریپت‌های PHP مستقل (بدون نیاز به DB):** شامل `index.php`، صفحات فرعی PHP، فایل‌های API (خروجی JSON)، پردازش فرم‌های GET/POST و سشن‌های PHP.

### به‌روزرسانی سایت:
- در ردیف هر سایت، دکمه **«به‌روزرسانی»** را بزنید و ZIP جدید را ارسال کنید. سیستم ابتدا محتوا را در پوشه موقت بررسی کرده و سپس نسخه جدید را با نسخه فعلی جایگزین می‌کند.

### حذف سایت:
- دکمه **«حذف»** را بزنید و تأیید کنید. پوشه فیزیکی مربوطه در `public_html/{slug}/` و رکورد آن در پنل بدون آسیب به سایر سایت‌ها پاک خواهد شد.

## ۵. نکته بسیار مهم درباره آدرس‌دهی زیرمسیرها (Subpaths)

هنگامی که سایتی در زیرمسیر (مانند `https://example.com/mysite/`) میزبانی می‌شود:

1. **از آدرس‌های نسبی استفاده کنید:**
   ```html
   <!-- درست: مسیر نسبی -->
   <link rel="stylesheet" href="./css/style.css">
   <script src="./js/app.js"></script>
   <a href="./about.html">درباره ما</a>
   ```
2. **یا از تگ base در head صفحه استفاده نمایید:**
   ```html
   <!-- تعیین ریشه زیرمسیر برای کل صفحه -->
   <base href="/mysite/">
   <link rel="stylesheet" href="css/style.css">
   ```
3. **از نوشتن آدرس ریشه مطلق خودداری کنید:**
   ```html
   <!-- نادرست در زیرمسیر: درخواست را به https://example.com/css/style.css می‌فرستد -->
   <link rel="stylesheet" href="/css/style.css">
   ```

## ۶. ملاحظات امنیتی در هاست اشتراکی cPanel

1. **مرز دسترسی PHP:**
   اسکریپت‌های PHP آپلودشده با سطح دسترسی حساب cPanel شما اجرا می‌شوند. در هاست‌های اشتراکی ایزولاسیون سطح کانتینر یا هسته (مانند Docker) وجود ندارد. **فقط فایل‌ها و اسکریپت‌های مطمئن را آپلود کنید.**
2. **مجوز فایل‌ها (File Permissions):**
   سیستم به‌صورت خودکار پوشه‌ها را روی `0755` و فایل‌ها را روی `0644` تنظیم می‌کند. به هیچ عنوان از مجوز ناامن `0777` استفاده نمی‌شود.
3. **حفاظت از فایل‌های سیستمی:**
   پوشه‌های `panel_core` و `panel_data` از طریق فایل‌های `.htaccess` داخلی و کدهای PHP به گونه‌ای قفل شده‌اند که دسترسی مستقیم مرورگر به فایل‌های پیکربندی و لاگ‌ها کاملاً مسدود (`403 Forbidden`) است.

---

## ۷. فایل‌های نمونه برای آزمایش اولیه

دو سایت آماده در پوشه `samples/` قرار دارد که می‌توانید بلافاصله در پنل دیپلوی کنید:
- **`samples/sample-static.zip`:** سایت استاتیک کامل شامل جاوااسکریپت تعاملی، استایل‌های مدرن و لینک داخلی به `about.html`.
- **`samples/sample-php.zip`:** وب‌اپلیکیشن مستقل PHP بدون دیتابیس برای آزمایش اجرای PHP، پردازش فرم‌های POST، تست پارامترهای GET، مدیریت Session و پاسخ‌دهی JSON API.

---

## ۸. اجرای تست‌های خودکار

برای اجرای کامل تست‌های امنیتی، استخراج، احراز هویت و تست شبیه‌سازی سرور HTTP:
```bash
php tests/run_all_tests.php
```
این دستور موارد زیر را بررسی و تأیید می‌کند:
- اعتبارسنجی Slugها و مسدودسازی ورودی‌های ناامن و رزروشده
- عملکرد توکن‌های CSRF و قفل‌گذاری Brute-Force
- استخراج ZIP و مقابله با حملات Zip Slip و Zip Bomb
- حذف خودکار پوشه اضافی داخل ZIP
- اجرای واقعی تست سرور HTTP محلی و تست جریان کامل از نصب تا دیپلوی و حذف.
